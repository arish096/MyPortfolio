## 🚀 About the Project

This portfolio is my personal space on the web to showcase my work, skills, and interests in technology.

Built with a clean interface, responsive layouts, and interactive elements, it includes an AI-powered chatbot that helps visitors learn more about my projects and development journey.

## ✨ Features

- 🎨 Modern and responsive user interface
- 🌈 Theme and color customization
- 🤖 AI-powered portfolio chatbot
- 💬 Chatbot powered by OpenRouter
- 📂 Project showcase
- 🛠️ Skills and tools section
- 📱 Mobile-friendly design
- ⚡ Smooth animations and interactive components

## 💻 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/arish096/MyPortfolio.git
cd MyPortfolio
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the frontend

```bash
npm run dev
```

### 4. Start the chatbot backend

Create a `.env` file in the project root:

```env
OPENROUTER_API_KEY=your_openrouter_api_key
OPENROUTER_MODEL=openrouter/free
```

Then run:

```bash
npm start
```

> Keep your API key private. Never commit your `.env` file to GitHub.
